# Mission Center 0.5.1

0.5.1 將正式 Plugin runtime 切換為 Rust CLI，保留 `tasks.md` 作唯一 lifecycle truth。

## Highlights

- 四平台 frozen binaries：Windows x86_64、Linux x86_64、macOS x86_64、macOS arm64。
- SHA-256 manifest、離線 verifier、無自動下載／編譯／Python fallback。
- 原子 transition、Completion Passport、Doctor、claim/lease/fencing 與 operation receipt。
- bounded pulse/handoff、Runtime/HUD、research/Steelman/Critic/Shift-Loss policy contracts。
- native publish/install/registration/reconcile/rollback transaction。
- MC-001～MC-060 retrospective validation；不可復原的人工證據維持 `unknown`。

## Compatibility boundary

Python oracle 只保留於 source checkout，供 differential testing、歷史重驗與 migration
diagnostics；正式 staged Plugin 不包含 Python runtime scripts 或 dependency。

## Upgrade and rollback

安裝前必須驗證完整四平台 manifest 與選定 binary checksum。若 delivery 結果未知，
以原 operation ID 執行 reconcile，不得另送。rollback 只接受未遭竄改、與安裝 digest
一致的 receipt；衝突時 fail closed，保留現場供人工處置。
