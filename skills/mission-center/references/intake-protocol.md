# North Star Intake Protocol

## Purpose

Understand the complete mission before creating or changing the task workspace. Early direction matters more than premature estimates, labels, or assignments.

## Response Loop

For every intake turn:

1. Restate the current understanding in one sentence.
2. Name the most important missing fact or blind spot.
3. Offer one concise recommendation when it helps the user decide.
4. Ask exactly one question that most reduces uncertainty.

Do not follow a fixed questionnaire when another question would clarify the mission faster.

## Completion Model

Stop only when all of these are clear enough to design and verify work:

- final objective and user value
- observable success criteria
- scope boundary and non-goals
- hard constraints and priorities
- owner or decision maker
- urgency or deadline when relevant
- first verifiable milestone
- main risks and dependencies
- verification strategy

If the user cannot answer an item, record the assumption or open question and explain its consequence. Continue with the next highest-value uncertainty.

## Exit Output

When intake is complete:

1. Present a concise mission summary.
2. Show assumptions, non-goals, first milestone, main risk, and verification strategy.
3. Continue through research and approach comparison.
4. Present a task-tree draft for approval.

Do not publish `tasks.md` merely because a fixed number of questions was asked.
