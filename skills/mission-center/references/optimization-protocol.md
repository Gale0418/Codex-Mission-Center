# Adaptive Optimization Protocol

Mission Center is the task operating system. Optimization is an optional decision module invoked after Prior Art; it never replaces task lifecycle, verification, or human approval.

## Project Profile

Create a versioned `ProjectProfile` from the current repository only. Classify task type, parameter shape, repeatable measurement, noise, reversibility, risk, budget, and relevant local cases. Unknown evidence stays unknown.

## Modes

- `skip`: deterministic or low-value work where optimization adds overhead.
- `decision`: compare a small number of discrete alternatives with a trade study and scenario stress test.
- `hybrid`: combine evidence-based judgment with bounded experiments.
- `experimental`: use repeatable measurements and a declared experiment manifest.
- `research_spike`: collect missing evidence before assigning a numerical method.

Never disguise subjective scoring or non-repeatable observations as numerical optimization. `tasks.md` remains the only task lifecycle and ordering source. Optimization output may recommend `Review`, but cannot promote a task or strategy automatically.

## Expert Profiles

Profiles are routing contracts, not personalities.

| Profile | Mission | Use when | Inputs | Artifact | Non-goal | Verification |
| --- | --- | --- | --- | --- | --- | --- |
| Codebase Analyst | Bound the local system and constraints | Repository behavior is unclear | Source, tests, history | Evidence map | Inventing requirements | Reproducible local citations |
| Researcher | Compare standards and prior art | External facts affect the choice | Problem, constraints, sources | Prior-art matrix | Copying role prompts | Primary-source and license check |
| Architect | Select boundaries and contracts | Multiple components interact | Evidence, risks, options | Decision record | Premature implementation | Invariants and failure modes reviewed |
| Implementer | Deliver the smallest safe slice | Direction is approved | Contract, tests, task | Working change | Unrelated refactors | Focused automated tests |
| Verifier | Independently test claims | A result may be promoted | Acceptance criteria, artifacts | Verification evidence | Self-approval | Deterministic check plus evaluator where useful |
| Performance/Cost Optimizer | Improve measurable trade-offs | Metrics are repeatable | Manifest, baselines, budget | Pareto candidates | Fake composite scores | Hard constraints and held-out cases |

## Output

Machine-readable artifacts belong under `output/mission-center-optimization/`. Add `MissionCenter/experiments.md` only when an engineering experiment actually runs. Historical learning is limited to the current repository and begins with rules, structured classification, and local case retrieval—not a trained local neural network.
