# Snapshot Format

## Purpose

Capture a reopenable checkpoint for a MissionCenter workspace.

## Recommended Sections

- `Captured at`
- `Project`
- `Cycle`
- `Goal`
- `Progress`
- `Active tasks`
- `Blocked tasks`
- `Recent decisions`
- `Open questions`

## Guidance

- Keep the snapshot short enough to review quickly.
- Treat the snapshot as a restored starting point, not a replacement for the live workspace.
- Regenerate after meaningful scope or status changes.
