# Activity Log Format

## Purpose

Record why the workspace changed, not just what changed.

## Entry Format

- `Timestamp`
- `Change`
- `Reason`
- `Impact`

## Guidance

- Keep entries short.
- Write one entry per meaningful update.
- Prefer timestamped notes in `project.md`, then sync the summary if needed.
- Use the log to explain scope changes, blocked work, reopens, and closeout decisions.
