# INC-002 — 跨日 derived view 假新鮮

## Summary
Canonical bytes 不變時，隔日 `status` 仍可能回報 fresh。

## Impact

## Root cause
Freshness 只有 source fingerprint，沒有 organized date 維度。

## Final fix
