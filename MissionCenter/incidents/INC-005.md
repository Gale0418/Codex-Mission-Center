# INC-005 — Markdown Parser 漂移

## Summary
不同 CLI 對 escaped pipe、反斜線與 malformed row 的判定不一致。

## Impact
同一 `tasks.md` 可能在 sync、Doctor、Runtime 或 Snapshot 得到不同結果。

## Root cause
多個模組各自實作 `split('|')` 或近似 parser。

## Final fix
集中至 `scripts/common/markdown_table.py`，提供單表與多表 API。

## Verification evidence
escaped pipe、CRLF、malformed、多表與 consumer 回歸測試。
