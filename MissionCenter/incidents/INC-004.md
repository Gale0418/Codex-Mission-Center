# INC-004 — Post-commit 弄髒工作樹

## Summary
舊 hook 在 commit 完成後執行 sync 再 normalize。

## Impact
剛提交的 repo 可能立即出現未提交 canonical 變更，且 derived state 使用正規化前資料。

## Root cause
把可阻止提交的驗證錯放到 notification-only post-commit。

## Final fix
安裝唯讀 check-only pre-commit，保留使用者既有 post-commit。

## Verification evidence
Python 與 PowerShell hook tests；Git githooks 官方契約。
